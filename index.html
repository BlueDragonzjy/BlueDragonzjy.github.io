研途 Gmail 匯入

把 Gmail 收件匣中需要採取行動、而且有明確截止日期的通知，整理成私人工作台上的待辦事項。

為什麼需要 Gmail 授權

工作流程用 Gmail API 的唯讀權限檢查收件匣，以主旨和純文字郵件內容判斷是否有要做的事與截止日期。符合條件的通知會保留期限及原信連結，方便使用者回到 Gmail 核對。

查看資料使用、保存與刪除方式 →

匯入流程

  1. 使用者在 Google 的授權畫面允許 Gmail 唯讀存取。
  2. GitHub Actions 定期檢查指定收件匣的新信，辨識課程、助教或其他限時通知。
  3. 符合條件的通知寫入需登入的私人研途工作台，供使用者查看與核對。

使用條款

這項工具供工作台擁有者整理自己有權存取的郵件。匯入內容是個人待辦提醒，正式期限、時間與分工請以原始通知為準。

你可以隨時在 Google 帳戶取消 Gmail 授權，或停用自動匯入。若對服務或資料使用有疑問，請使用 Google 授權畫面列出的支援電子郵件。
